# Nexus Store: Telegram-магазин и админ-панель

Рабочий каркас бота на `aiogram 3`. Уже реализованы:

- команда `/menu` и главное меню с обложкой;
- каталог с категориями ChatGPT, Claude, Gemini, Notion, Grok, Perplexity, Netflix, Duolingo и CapCut;
- кошелёк с быстрыми суммами и вводом своей суммы;
- экраны бонуса, профиля, техподдержки и «прочее»;
- обложки из папки `brand-covers` в соответствующих разделах;
- закрытая админ-панель на `/admin` с товарами, остатками автовыдачи,
  покупателями, балансами, покупками и статистикой;
- PostgreSQL-хранилище.

## Запуск на Hostless

1. Загрузите все файлы проекта вместе с папкой `brand-covers`.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и укажите настоящий `BOT_TOKEN` от `@BotFather`.
4. Добавьте `DATABASE_URL` PostgreSQL и длинный случайный `ADMIN_SECRET`.
   База создаст таблицы автоматически при первом запуске.
5. При необходимости добавьте ссылки на документы в `WARRANTY_URL`, `TERMS_URL`, `PRIVACY_URL`.
6. Команда запуска: `python bot.py`.

После деплоя откройте `https://ваш-домен/admin` и введите значение
`ADMIN_SECRET`. В панели есть разделы:

- **Обзор** — графики выручки, покупок, посетителей и новых покупателей по дням
  (7 / 30 / 90 дней), динамика к прошлому периоду, статусы заказов, топ товаров
  и категорий, блок «Требует внимания» (оплаченные заказы без товара, закончившиеся
  и заканчивающиеся товары, товары без категории). Данные отдаёт
  `GET /api/admin/analytics?days=30&tz=180`.
- **Товары** — поиск, фильтры, правка цены прямо в таблице, переключатель показа
  в каталоге и боковая карточка: название, описание, категория, автовыдача
  (правка, удаление и массовое добавление позиций) и удаление товара.
- **Категории** — порядок показа и видимость прямо в таблице.
- **Покупатели** — поиск, сортировка, быстрые +5 / +10 USD и пополнение на любую
  сумму по @username или Telegram ID (`POST /api/admin/customers/id/{id}/balance`).
- **Покупки** — фильтры по статусам и поиск по заказам.

Панель обновляется раз в минуту; `/` — поиск, `Esc` — закрыть окно.
При первом запуске в пустую базу добавляются исходные категории: ChatGPT,
Claude, Gemini, Notion, Grok, Perplexity, Netflix, Duolingo, CapCut и Spotify.
Покупатель сначала выбирает категорию, затем товар внутри неё. Примеры
товаров вроде ChatGPT Plus и ChatGPT Pro создаются отдельно через панель;
их цены задаёт владелец магазина.

## Автовыдача через Crypto Pay

1. В `@CryptoBot` отправьте `/pay`, создайте приложение и скопируйте его API token.
2. Добавьте токен в `CRYPTO_PAY_TOKEN` и сгенерируйте отдельный длинный
   `CRYPTO_PAY_WEBHOOK_SECRET` в переменных Hostless.
3. В настройках приложения Crypto Pay включите Webhooks и укажите адрес:
   `https://ваш-домен/api/payments/crypto/<CRYPTO_PAY_WEBHOOK_SECRET>`.
4. Создайте товар и добавьте хотя бы одну строку в «Автовыдачу» через `/admin`.

После оплаты Crypto Pay присылает подписанное событие `invoice_paid`: бот
проверяет подпись, резервирует одну невыданную строку в PostgreSQL и отправляет
её покупателю. Повторное уведомление не выдаст товар второй раз.

## Запуск как App на Hostless

В проекте есть `hostless.yaml`: он фиксирует один экземпляр бота и проверяет
`/health`. Бот одновременно работает с Telegram и отдаёт HTTP-ответ на этом
пути, поэтому успешно проходит проверку App и сохраняет HTTPS-адрес для
будущего Telegram Web App.

Покупатели появляются в базе после первого `/start` или `/menu` в боте.
Раздел «Покупки» и выручка заполняются оплачиваемыми заказами; подключение
конкретного платежного провайдера должно создавать записи в таблице `orders`.

## Премиум-эмодзи и доллары

Все цены, пополнения и новые счета Crypto Pay — в **USD**. При обновлении
числа в базе **не пересчитываются по курсу**: прежняя цена `1.00` становится
`1.00 USD`. Проверьте цены и балансы до открытия продаж. Старые созданные
счета Crypto Pay остаются в своей исходной валюте — обновление их не меняет.

- **Категории → Изменить → Эмодзи** — выбор логотипа категории. Все товары
  наследуют его и в кнопке списка, и перед названием в карточке. Для исходных
  категорий (ChatGPT, Claude, Gemini и др.) логотипы уже настроены.
- **Эмодзи** — изменение значков описания, доллара, количества и меню.
  По умолчанию описание: `5843843420468024653`, количество: `5877260593903177342`.
  «По умолчанию» возвращает исходный значок.
- Каталог содержит 1 923 уникальных ID из
  [curated_packs.json](https://github.com/abbosahmad/telegram-premium-emojis/blob/main/catalog/curated_packs.json).
  Наборы, порядок и категории сохранены; ID всегда хранятся строками.
  Можно искать, фильтровать наборы и типы, листать страницы и вставлять свой
  ID либо `tg-emoji` / `custom-emoji-element`. Отправка эмодзи боту возвращает ID.
- Предпросмотр загружается с помощью `getCustomEmojiStickers` и `getFile`.
  Это оригинальный статичный WEBP или настоящая миниатюра для TGS/WEBM,
  **не анимация**. Токен бота не передаётся браузеру; все API превью закрыты
  админской сессией, файлы кэшируются. Недоступное превью явно помечается
  пунктиром и показывает обычный emoji-заменитель.
- В редакторе товара есть обновляемый предпросмотр карточки. Изменения
  настроек применяются на следующем открытом экране бота без перезапуска;
  уже отправленные сообщения автоматически не редактируются.
- Telegram допускает один `icon_custom_emoji_id` в inline-кнопке. Поэтому
  кнопка товара содержит логотип категории и текст `$1.00`; премиум-доллар
  находится в тексте карточки и сообщения об оплате.

При рестарте автоматически добавляются `categories.custom_emoji_id`,
`categories.emoji_fallback` и таблица `shop_settings`. Товары и остатки не удаляются.
Для доступности премиум-значков соблюдайте ограничения Telegram: владелец
бота должен иметь Premium либо бот должен отвечать требованиям Fragment.

Проверки кода: `python -m unittest discover -s tests -v` и `node --check admin.js`.
